# Contributing

Issues are welcome: bug reports, errors, questions. Please say what you ran, what you expected, what you saw, and
the versions involved. Remove any keys, tokens, account names or private text first.

Pull requests are not accepted for now. The code is the reference implementation of `PROTOCOL.md` as published
with the paper, and it changes only when the protocol does.

Security problems go through a private report, not an issue: see `SECURITY.md`.
